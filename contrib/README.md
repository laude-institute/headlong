# Optional integrations

[OpenCode](opencode/README.md) provides bounded coding delegation with retained candidate evidence. Install and enable it explicitly for each identity. Contrib packages are not installed or advertised by default.

[Skill compiler](skill-compiler/README.md) generates validation cases for trusted skills and saves reports. Install it explicitly with `skills install /path/to/headlong/contrib/skill-compiler` in the selected agent's shell. Model calls can incur charges, and test execution retains the caller's filesystem and credential access.
